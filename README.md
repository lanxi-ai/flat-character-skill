# 无相绘境 · Formless Tales

**以色块重塑人物，用场景延伸故事。**

一套面向人物图像的色块插画创作 Skill。支持真人照片、动漫人物、角色插画和立绘，将人物转化为无五官、低细节、大色块的场景作品，保留发型、服饰、姿态等视觉特征，并结合画面线索设计适配环境。

可供支持 [Agent Skills 格式](https://agentskills.io/specification) 的 AI 工具使用，也可作为提示词工作流手动使用。核心规则不依赖特定平台、模型或 API。

## 风格与能力

- **保留人物特征**：延续发型、服装轮廓、主要配色、姿态和标志性配件。
- **统一色块画法**：默认省略面部五官，合并纹理与细碎阴影，以大色面和流畅轮廓组织层次。
- **主动设计场景**：结合可见服饰、道具、动作及用户说明，选择具体环境，让人物与场景形成自然关系。
- **适配不同取景**：支持特写、半身、全身和多人图片，默认保留原取景范围与人物关系。
- **接受创作偏好**：可指定场景、姿势、构图、画幅、简化程度及背景类型。
- **提供两种输出**：直接生成图片，或只输出可复制的提示词。

## 快速开始

### 使用 Skill

将 [`skills/artifact-template-flat-character`](skills/artifact-template-flat-character) 整个目录放入所用工具规定的技能目录，或使用该工具支持的导入方式。保留目录结构；不同工具的安装位置和调用语法可能不同。

如果工具支持从 GitHub 安装 Skill，可提供此目录地址：

```text
https://github.com/lanxi-ai/flat-character-skill/tree/main/skills/artifact-template-flat-character
```

上传一张人物图片，再让工具使用 `artifact-template-flat-character`：

```text
使用 artifact-template-flat-character 处理这张人物图片。
保留人物特征、原姿势和原取景，为人物设计适配的具体场景。
```

支持 `$技能名` 调用方式的工具中，可写成 `$artifact-template-flat-character`。

### 手动使用提示词

不支持 Skill 导入时，打开 [通用提示词](PROMPT.md)，复制其中的提示词，与人物图片一起发送给支持图像输入的 AI 工具。

需要更具体的提示词结构或实例，可阅读 [提示词示例](skills/artifact-template-flat-character/references/prompt-patterns.md)。

## 使用示例

**真人半身照**

```text
使用无相绘境处理这张照片。保留发型、衣着、姿势和半身取景，
画面采用无五官的大色块风格，场景设为午后的窗边阅读区。
```

**动漫人物**

```text
使用无相绘境处理这张人物图。保留服装配色、配件和原姿势，
结合人物的可见特征设计具体环境，人物和背景使用统一的色块画法。
```

**只获取提示词**

```text
使用无相绘境分析这张人物图，只给我可复制的成稿提示词，不生成图片。
```

**指定空背景**

```text
使用无相绘境处理这张人物图片，保留原取景，背景完全透明。
```

## 工作方式

读取人物图像 → 提取视觉特征 → 设计具体场景 → 统一色块画法 → 检查构图与人物关系。

原图已有合适环境时，会连同人物一起简化；原图背景为空时，会主动设计场景。用户明确指定的内容优先于默认设置。

默认保留原姿势与取景，特写和半身图片不会自动补成全身。场景设计属于创作联想，不用于判断真人身份、职业或角色的官方设定。

## 环境要求

- 分析人物图像需要图片读取能力。
- 直接出图还需要支持人物图片输入的图像生成或编辑能力。
- 缺少生图能力时，可使用提示词模式，再将提示词和人物图片交给合适的图像工具。

本项目提供创作规则和提示词，不附带模型、API 密钥或付费服务。不同平台的图片传递方式与生成效果会有所差异；复杂装备、遮挡和多人构图可能需要调整。
