# 提示词骨架与示例

用于把当前图片的观察转为可执行提示词。正文中的示例人物是虚构输入，不能当作当前图片的事实。实际交付时填满变量，并省去不适用的段落。

## 通用骨架

以所附人物图片为内容依据，将其重绘为无五官、低细节、大色块的平面场景插画。

保留【人物数量、相对位置】【可见肤色、体型与年龄观感】【发型轮廓】【服饰形状和主配色】【关键配件或道具】。维持【原姿势、视角和取景范围】，不扩展未展示的身体部分。主体采用【从图片提取的主要颜色】，保持颜色分区和面积关系。

使用连贯大色面、流畅曲线与少量结构性角面。将头发归并为主要发束，衣服按衣片结构概括，删减纹理、细碎褶皱和反光。保留关键装饰的大形，每个主要部件采用基色及少量清楚的明暗色面。脸部保留原有肤色关系、脸形和朝向，省略眼、鼻、嘴与写实面部阴影；【如适用，保留面具或非人头部的必要结构】。

环境采用【用户指定、原图已有或本次设计的具体地点】，以【两三种可辨认的设施、建筑或自然形态】说明地点。人物保持【动作】，与【桌沿、地面、座椅、栏杆或其他空间参照】形成合理关系。使用【背景的配色与光向】衬托人物，保持光照、遮挡和尺度一致；环境同样以大色块概括，细节少于主体。

构图维持【特写、半身、全身或多人范围及比例】，不裁去【原图已展示的重要部位】。避免碎纹理、厚黑描边、密集三角切面、写实皮肤、无依据换装和身体结构错误。默认不添加文字或标识。

用户明确要求透明或纯色背景时，替换整个场景段，勿保留互相冲突的场景要求。若只能接收单段提示词，将各段合并即可，不需要另设“负面提示词”参数。

## 仅有文字描述

用户只要提示词且外观信息足够时，把“所附图片”“保留原图”改成“根据以下描述”，明确取景、人物特征和场景均来自已提供的描述，不宣称核对过图片。不要捏造附件或视觉观察。需要转换指定图片时，先取得可用源图。

## 示例：真人照片，胸部以上肖像

假设输入：一位成年人物，棕色卷发、棕色皮肤、橄榄绿外套和圆形耳饰，三分之二侧向，取景至胸部，背景为纯色；用户要求保持取景。

> 依据所附肖像重绘为无五官平面色块插画。保留棕色卷发的大轮廓、棕色肤色、橄榄绿外套、圆形耳饰及原有体型和成年外观，保持三分之二侧向与胸部以上取景，不补出腰部、腿部或手。脸部保留脸形与朝向，以协调的棕色色面平涂，省略眼鼻嘴和写实面部阴影。头发归并为几束流畅卷曲的大形，外套用橄榄绿和深绿表现衣片，不描绘毛孔、发丝或织物纹理。设计午后临窗阅读角：人物后方可见米白窗框、简化的低矮书架和窗外大树冠，少量暖色侧光与人物一致；这是画面环境设计。背景降低细节密度，用明度差衬出头发和肩部。画幅与源图一致，无文字标识。

此例的场景来自配色与构图联想，不代表判断人物的职业、身份或生活经历。

## 示例：动漫立绘，全身构图

假设输入：深蓝短发、米白长风衣、橙色围巾，手持折叠伞，站姿；原图无环境。

> 以所附人物立绘为依据，保留深蓝短发、米白长风衣的轮廓和衣片分区、橙色围巾、折叠伞与原站姿。保持原有肤色、体型和完整全身构图，头顶、鞋底及伞尖留出空间。脸部无眼鼻嘴，用接近原肤色的单纯色面表现。头发、衣摆和围巾以大色面与流畅曲线概括，衣服只用少量结构阴影，省略织物和细小褶皱。场景设为雨后车站的有顶站台：简化的站台立柱、长椅、轨道及远处雨棚形成清楚层次。人物双脚接触站台地面，伞尖位置合理；地面用几块低对比冷灰色面概括湿润反光，不做写实倒影。暖橙围巾与冷灰背景形成对比，保留完整轮廓，无文字标识。

## 示例：多人照片，用户指定纯色背景

假设输入：两位成年人物坐在长椅上，左侧黑色短发、浅蓝衬衫，右侧褐色长发、红色上衣；图片裁至膝盖，用户明确要求米白背景。

> 将所附合照重绘为无五官的大色块插画，保持两人的左右位置、相对身高、各自可见肤色、体型与成年外观。分别保留左侧黑色短发和浅蓝衬衫、右侧褐色长发和红色上衣，不交换衣服和配色。保留原坐姿、手臂关系、长椅支撑及裁至膝盖的取景，不补出小腿和脚。脸部保留脸形与朝向，省略眼鼻嘴。头发、衣服和长椅均用连贯大色面与少量明暗分区概括，省略纹理。按要求使用均匀米白背景，不增添房间、建筑或风景。保持主体与背景分离，画幅与源图一致，无文字标识。

## 针对性修订

| 主要偏差 | 修订重点 |
|---|---|
| 只是降色，纹理仍繁碎 | 将相邻细节合并为主要发束、衣片与结构阴影 |
| 人物变得通用化 | 恢复当前源图最具辨识度的具体轮廓和配色分区 |
| 脸变白或改变体型 | 重申源图的肤色、脸形、体型和年龄观感 |
| 特写被扩成全身 | 重申原取景边界，在该范围内设计环境 |
| 没有具体环境 | 除用户要求空背景外，补入明确地点与可辨认结构 |
| 背景太繁复或像贴图 | 降低细节密度，统一尺度、光向、遮挡与接触关系 |
| 多人外观串位 | 分别列出各主体的位置、发型、服饰与道具 |

每次修订优先解决最明显的问题，不无限扩写禁止列表。
